## Submission checklist (ordered)

1. **Enroll** in the Apple Developer Program ($99/yr) and accept the latest agreements.
2. **Enroll in the Small Business Program** (App Store Connect → Agreements) → 15% commission
   (≈ $1.69 net per $1.99 sale) instead of 30%.
3. **App Store Connect → create app**: platform macOS, name, primary language, bundle ID
   `com.isaaccalvo.Espresso`, SKU.
4. **Packaging (needs Xcode):**
   - Install Xcode. Easiest path: create a thin **Xcode macOS App** target and add the
     `Sources/EspressoKit` + `Sources/Espresso` files (or open `Package.swift` and add an app
     target), set deployment target macOS 13, `LSUIElement = YES`, app icon = `AppIcon.icns`.
   - Enable **App Sandbox** (use `Espresso.entitlements` — sandbox is the only entitlement).
   - Signing: **Apple Distribution** cert + **App Store** provisioning profile; **Hardened
     Runtime** is automatic for MAS.
5. **Set price** ($1.99 tier), availability (all territories), category (Utilities), age (4+).
6. **Privacy:** answer the questionnaire → Data Not Collected.
7. **Upload the build** via Xcode Organizer (Archive → Distribute → App Store Connect) or
   Transporter.
8. **Add metadata:** the copy above + screenshots + support URL.
9. **Submit for review.** Typical turnaround: a few days.
10. **If rejected under 4.2 (minimum functionality):** emphasize the timed brews, battery
    safety, display option, and launch-at-login in the review notes — the app is well past a
    “single button.”

## Realistic expectations (candid)
The category is crowded and Amphetamine (free) dominates. A paid $1.99 entrant survives on
**charm + presentation**: the cup mascot, the draining animation, great screenshots, a
memorable name, and a small launch push (Product Hunt, r/macapps, Mastodon). Treat early
revenue as “espresso money,” and lean on the cuteness — that’s the differentiator.
